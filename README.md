# 🎮 로또 게임 구현 기능 목록

## 1. 로또 구매 기능

* **로또 구입 금액 입력**
    * 사용자로부터 로또 구입 금액(문자열)을 입력
    * 입력값이 숫자가 아닐 경우 `IllegalArgumentException`을 발생
    * 입력값이 양수가 아닐 경우 `IllegalArgumentException`을 발생
    * 입력값이 1,000원 단위로 나누어 떨어지지 않을 경우 `IllegalArgumentException`을 발생
* **로또 자동 발급**
    * 구입 금액을 1,000원으로 나누어 구매할 로또 개수를 계산
    * 1~45 범위의 중복되지 않는 6개 숫자를 자동으로 발급
* **구매 내역 출력**
    * 구매한 로또의 총 개수를 출력
    * 구매한 모든 로또의 번호를 오름차순으로 정렬하여 출력

## 2. 당첨 번호 및 보너스 번호 입력

* **당첨 번호 6개 입력**
    * 사용자로부터 쉼표(`,`)로 구분된 당첨 번호 6개를 입력
    * 입력 형식이 올바르지 않거나(숫자, 쉼표 외 문자 포함) 6개가 아닐 경우 `IllegalArgumentException`을 발생
    * 당첨 번호가 1~45 범위를 벗어날 경우 `IllegalArgumentException`을 발생
    * 당첨 번호 6개 중 중복된 숫자가 있을 경우 `IllegalArgumentException`을 발생
* **보너스 번호 1개 입력**
    * 사용자로부터 보너스 번호 1개를 입력받습니다.
    * 입력값이 숫자가 아니거나 1~45 범위를 벗어났을 경우 `IllegalArgumentException`을 발생
    * 보너스 번호가 이미 입력된 당첨 번호 6개와 중복될 경우 `IllegalArgumentException`을 발생

## 3. 당첨 결과 계산

* **당첨 통계 계산**
    * 구매한 모든 로또를 당첨 번호, 보너스 번호와 비교하여 등수를 결정
    * 등수별(3개 일치 ~ 6개 일치) 당첨 개수를 집계
    * 총 수익률 계산

## 4. 결과 출력

* **당첨 통계 출력**
    * 5등(3개 일치)부터 1등(6개 일치)까지 각 등수별 당첨 개수를 형식에 맞춰 출력
    * 계산된 총수익률을 소수점 둘째 자리에서 반올림하여 첫째 자리까지 출력

  * 사용자 입력 과정(구매 금액, 당첨 번호, 보너스 번호)에서 `IllegalArgumentException`이 발생할 경우, <br>`[ERROR]`로 시작하는 예외 메시지를 출력 후,
  예외 발생 시, 프로그램을 종료하지 않고 해당 입력 단계부터 다시 입력
